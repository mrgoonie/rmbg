Available Endpoints

GET /health

Health check endpoint to verify API status.

GET /models

List all available background removal models.

POST /remove-background

Remove background from an image.

Available Models

u2netp

Resolution: 320px | Size: ~4.5MB

Fast and lightweight model for general use.

modnet

Resolution: 512px | Size: ~25MB

Balanced quality and performance.

briaai

Resolution: 1024px | Size: ~44MB

High-quality results for production use.

isnet-anime

Resolution: 1024px | Size: ~168MB

Specialized for anime and manga images.

silueta

Resolution: 320px | Size: ~43MB

Optimized for portrait and people photos.

u2net-cloth

Resolution: 768px | Size: ~170MB

Specialized for clothing and fashion.

Usage Examples

cURL

# Basic usage with default model
curl -X POST http://localhost:3000/remove-background \
  -F "image=@photo.jpg" \
  --output result.png

# With specific model
curl -X POST http://localhost:3000/remove-background \
  -F "image=@photo.jpg" \
  -F "model=briaai" \
  --output result.png

# With custom resolution
curl -X POST http://localhost:3000/remove-background \
  -F "image=@photo.jpg" \
  -F "model=briaai" \
  -F "maxResolution=4096" \
  --output result.png

JavaScript (Fetch API)

const formData = new FormData();
formData.append('image', fileInput.files[0]);
formData.append('model', 'briaai');
formData.append('maxResolution', '2048');

const response = await fetch('http://localhost:3000/remove-background', {
  method: 'POST',

});

const blob = await response.blob();
const url = URL.createObjectURL(blob);
// Use the URL to display or download the image

Python

import requests

url = 'http://localhost:3000/remove-background'
files = {'image': open('photo.jpg', 'rb')}
data = {'model': 'briaai', 'maxResolution': '2048'}

response = requests.post(url, files=files, data=data)

with open('result.png', 'wb') as f:
    f.write(response.content)

Parameters

  • image (required): Image file (JPEG, PNG, WebP) - Max 10MB
  • model (optional): Model name - Default: "modnet"
  • maxResolution (optional): Max resolution in pixels (1-4096) - Default: 2048

Response

Returns a PNG image with transparent background on success, or JSON error message on failure.
